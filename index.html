What this is

OSINT Atlas is a curated catalogue of open-source intelligence tools and a pivot board. Paste a selector (a username, email, domain, IP, phone number, URL, image URL, crypto wallet, file hash or a name), and the pivot board builds the lookup links an investigator would open next, grouped by purpose.

Passive by design

  • The page loads only its own files. No analytics, cookies, fonts or trackers, and a strict Content-Security-Policy keeps it that way.
  • Selectors are never written to the address bar, history or storage. Links open with noreferrer, so services do not learn where you came from.
  • Stars and notes on tools are kept only in this browser (localStorage). Use Export to move them to another device.
  • No scraping and no API keys. The page builds links; you decide what to open.
  • Opening a link sends your query to that service. For sensitive cases, use a separate browser profile, a VPN or Tor, and research accounts.

Use it responsibly

Public does not mean fair game. Have a lawful purpose, collect only what you need, and respect privacy law such as the GDPR. Some listed services are aimed at specific countries or professions and have their own terms.

Contribute

Every tool lives in data/tools.json and every pivot in data/pivots.json. A script checks the format on every pull request, and a monthly job tests every link and flags tools that stopped responding. See the repository to suggest a tool or fix a link.
